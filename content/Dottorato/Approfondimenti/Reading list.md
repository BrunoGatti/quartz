
**1. Foundational Papers on Sparse Attention:**

• **“Generating Long Sequences with Sparse Transformers”**

_Authors:_ Child et al. (2019)

_Summary:_ Introduces the Sparse Transformer architecture, which utilizes sparse factorizations of the attention matrix to handle long-range dependencies efficiently.

_Link:_ [https://openai.com/index/sparse-transformer/](https://openai.com/index/sparse-transformer/)

• **“Longformer: The Long-Document Transformer”**

_Authors:_ Beltagy et al. (2020)

_Summary:_ Presents the Longformer model that employs a combination of local and global attention patterns to process long documents effectively.

_Link:_ [https://arxiv.org/abs/2004.05150](https://arxiv.org/abs/2004.05150)

  

**2. Adaptive Token Mechanisms:**

• **“Adaptive Token Sampling for Efficient Vision Transformers”**

_Authors:_ Fayyaz et al. (2021)

_Summary:_ Introduces a differentiable, parameter-free module that adaptively samples significant tokens in vision transformers, reducing computational costs.

_Link:_ [https://arxiv.org/abs/2111.15667](https://arxiv.org/abs/2111.15667)

• **“A-ViT: Adaptive Tokens for Efficient Vision Transformer”**

_Authors:_ Yin et al. (2022)

_Summary:_ Proposes a method to enable adaptive token computation in vision transformers by introducing an adaptive halting mechanism, leading to faster inference.

_Link:_ [https://openaccess.thecvf.com/content/CVPR2022/papers/Yin_A-ViT_Adaptive_Tokens_for_Efficient_Vision_Transformer_CVPR_2022_paper.pdf](https://openaccess.thecvf.com/content/CVPR2022/papers/Yin_A-ViT_Adaptive_Tokens_for_Efficient_Vision_Transformer_CVPR_2022_paper.pdf)

  

**3. Recent Advances in Sparse Attention:**

• **“Sparser is Faster and Less is More: Efficient Sparse Attention for Long-Range Transformers”**

_Authors:_ Lou et al. (2024)

_Summary:_ Introduces SPARSEK Attention, a novel mechanism that selects a constant number of key-value pairs for each query, achieving linear time complexity and constant memory footprint during generation.

_Link:_ [https://arxiv.org/abs/2406.16747](https://arxiv.org/abs/2406.16747)

• **“Adaptive Token Reduction for Efficient Large Multimodal Models”**

_Authors:_ Liu et al. (2024)

_Summary:_ Explores a token reduction mechanism that adaptively prunes visual tokens in multimodal models, maintaining performance while significantly reducing computational costs.

_Link:_ [https://arxiv.org/abs/2403.15388](https://arxiv.org/abs/2403.15388)
